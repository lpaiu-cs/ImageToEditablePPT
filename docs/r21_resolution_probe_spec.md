# R21 전체 검출 해상도 개발 대조

2026-09-09. R20에서고정bbox의전체해상도증가가종류TP1→5로이어졌다. 이제RPN/회귀를포함한전체검출에서효과를검사한다. R19/R20동결결과와제품기본값을보존한다.

R19 final.pt(SHA3c74f33ca5e98fdb9cc8ff585b71ff69e802dffa53529e4db580b351efcb8120)를고정한다. 동일RGB를min/max600/960,1200/1920,1800/2880세조건으로추론한다. score.95,기존torchvision NMS.5/detections100와nativepreset/noFill은변경하지않는다. RPN과bbox회귀를정상실행하며GTbbox/ROI는입력하지않는다. 학습/score재조정/조건간선택결과병합없음.

먼저원래CogBotRGB에서세조건의실제COM과수동17node개발장부사후진단을비교한다. 입력/모델/코드/명세를실행전후SHA확인한다. 600조건은R19원본후보·최종출력과동일해야한다. 차이가있으면버전/연산조건차이를먼저기록한다.

이미노출된R19eval48장에서도같은세조건을측정할수있다. 이는새로운독립평가가아닌개발회귀대조다. 수동장부와sourceannotations는추론후평가에만쓴다. 종류무시/종류포함TPFPFN,누락원인,실제COM을분리해보고한다. latency/GPUpeak를기록하되사람의수정시간과혼동하지않는다.

원본그림에서후보/종류가충분히개선되지않으면해상도만높이는방향을끝내고남는경계/도메인차이를후속가설로삼는다. 어떤조건도이개발실험만으로제품승인하지않는다. 전체목표는유용한편집가능PPT이며이부분실험의종료로완료처리하지않는다.
