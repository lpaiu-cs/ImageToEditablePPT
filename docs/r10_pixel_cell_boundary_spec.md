# R10 폐윤곽 대응의 원본1픽셀 계약

사용자는1픽셀 차이를 실패로 다루지 않는 방향을 승인했다. 기존 P 계약은 좌표차≤1픽셀과 IoU≥.98을 동시에 요구했다. 실제 COM의 `Build`는 `[313,169,403,229]`와 `[313,169,402,228]`로 양쪽 모두 닫힌 실제 경계이고 좌표 오차가1픽셀 이내지만 IoU≈.973 때문에 탈락했다. 동일 절대 오차에 대해 작은 박스일수록 불리한 면적비 gate가 중복으로 적용됐다.

새 `--pixel-agreement` arm은 threshold 간 후보 대응에 **원본 bbox 네 좌표 각각 차이≤1픽셀**을 사용하고 이때의 IoU≥.98은 요구하지 않는다. resize나 이미지 크기에 비례한 픽셀 허용치 확대는 하지 않는다. 1픽셀 초과는 여전히 기권한다. 실제 contour의 폐곡선/크기/사각성/면적 조건, 같은 arm 내부의 겹친 경쟁 경계 처리, 중복 억제와 OCR/의미 gate는 그대로다. 기존 기본 P 결과와 not_single 실패를 소급 변경하지 않는다.

이 변경은 새로운 의미 분류기가 아니다. 새로 살아난 photo frame/glyph/table 후보는 semantic 진단으로 따로 보고하며, 출력 승인에는 기존 내용·라벨·연결 조건이 필요하다. 독립96개 폐윤곽 대조군과 실제 COM20개 RGB, 노출된 복잡7개를 사전 고정 경로로 재실행한다. 1픽셀 허용이 모든 구조의 의미 정답을 보장한다고 주장하지 않는다.
