# R10 중첩 owner 경로 일치 계약

독립 실제 PPT→COM RGB 통합 검사에서 parent 내부 연결의 전부 누락과 child `Check`의 parent 제목 중복이 확인됐다. 기존 결과는 유지하고 `--nested-owners`라는 별도 실험 설정으로 수정한다.

1. OCR/색 계산의 제외 영역에는 기존 Canny 폐윤곽뿐 아니라 현 실행 union에서 **실제로 검증된 contour**도 포함한다. bbox로 새 사각형을 만들어 넣지 않는다. 기존 엄격한 내부 포함·0.8미만 면적·contour 내부 조건을 그대로 적용한다. 동일 bbox는 제외 목록에서 한 번만 센다.
2. 엄격하게 내부에 포함된 검증 owner가 두 개 이상이고 그중 둘이 공간적으로 떨어져 있는 parent에 한해서, tracing 동안만 container의 경계 마스크를 사용한다. child badge 하나/겹친 inner face 하나는 이 조건을 충족하지 않는다. parent 전체 내부를 지우지 않아 실제 선이 살아 있게 한다.
3. 임시 parent는 연결 종점 후보가 아니다. 따라서 parent로 직접 들어가는 링크는 이 arm에서 보수적으로 누락될 수 있다. 연결이 실제 raw/mask에서 관측되지 않으면 만들지 않는다. 기존 선 추적·B 중심선·H 화살촉 계약은 변경하지 않는다.
4. tracing이 끝나면 입력 shape들의 역할·종류·bbox·라벨을 그대로 복원한다. GT container 역할을 입력하거나 새 도형·헬퍼 객체를 만들지 않는다.

처음은 실패가 공개된 통합 대조군에서 재실행하고 실제 COM 렌더를 확인한다. 이는 개발 회귀이며 일반화 holdout 통과로 바꾸지 않는다. 사진 음성·기존 복잡7개 회귀도 별도로 확인한 뒤 고정 CLI 편입 여부를 판단한다.
