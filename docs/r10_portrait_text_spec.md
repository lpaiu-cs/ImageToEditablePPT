# R10 세로 라벨 독립 관측 계약

기존 closed-native-v2를 동결한 채 별도 실험한다. GT 문자열·기존 scene·그림별 방향 선택은 입력하지 않는다. 높이가 폭의3배 이상인 원본 폐윤곽 후보에만 적용한다.

원본 owner RGB와 자식 제외 마스크를 각각90도 양방향 회전한다. 각 방향에서 기존 공간 OCR의3배율 문자열/위치 일치 계약을 적용하고, 단일 행에 한해 실제 전체 행 픽셀을 인식 전용3배율로 다시 읽는다. 후자는 모두 동일 문자열이고 confidence≥.98이어야 한다. 두 방향 중 정확히 하나만 승인될 때만 방향을 정한다. 둘 다 승인/둘 다 기권이면 공백이다. 임계값을 실그림 결과에 맞추어 낮추지 않는다.

방향을 승인해도 해당 결과는 먼저 관측 결과이며 자동 production 승인이 아니다. native text-frame의 방향·글자 위치를 실제 PowerPoint에서 검증하기 전에는 배포 경로에 편입하지 않는다. 같은 OCR 모델의 반복 일치는 독립된 모델의 정답 증명이 아니다. 단일 행·세로 박스 밖은 기존 계약을 유지한다.

## 검증 후 통합 arm

관측 prototype의3개 세로 라벨과32개 glyph 대조군을 확인한 뒤 `--portrait-text` opt-in을 추가했다. 승인된 방향의 원본 OCR bbox/word bbox를 정확히 역회전하여 소유 영역·texture text 제외 좌표로 쓴다. 최종 native owner 자체를 회전시키지 않고 text-frame만 회전한다. 배경 채움에 대응하는 명시적 전경색을 써서 text 교체 시 theme white로 사라지는 결함을 막는다. 방향 관측이 기권하면 기존 원방향 owned-text 계약을 그대로 실행한다. 통합 결과는 다시 RGB부터 실행하고 실제 COM으로 확인한다.
