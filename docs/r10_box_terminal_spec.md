# R10-H: 확인된 폐윤곽 바깥 화살촉 관측

B는 방향을 바꾸지 않아 선만 복귀한 7개가 기존 방향 엄격 평가에서는 추가 오답으로 계산됐다. 별도 owner-pair 평가는 53개 모두 올바른 쌍이다. 따라서 문턱을 완화하거나 정답 방향을 공급하지 않고, 실제 화살촉 증거만 별도 관측한다.

범위는 B에서 원본 중앙선이 확인된 기존 2-owner 연결 중 무방향 직선뿐이다. 양쪽 노드는 G의 실제 닫힌 단순 윤곽 검사를 통과해야 한다. 노드 bbox 사각 영역을 지우면 원형 노드 근처의 촉이 잘리므로, 실제 관측된 폐윤곽 내부와 두께 2s 경계 띠만 관측에서 제외한다. 원본 RGB 자체는 변경하지 않는다.

축 양끝 ±6s 및 원본 노드 바깥에서 중앙 shaft와 같은 원본8CC를 본다. 좁은 corridor로 가지를 잘라 숨기지 않는다. 실제 물리셀 연속성≥.95/내부갭≤2s, 중앙 잔차≤3s, 전체 성분 잔차≤8s를 요구한다. 중앙 픽셀로 shaft 폭을 관측하고 기존 S의 촉 밑변·대칭·수렴 검사로 정확히 한쪽 촉을 확인한다. 반대편이 넓어졌거나 별도 가까운 성분이 있으면 기권한다. 방향이 이미 있는 연결은 덮지 않는다.

H는 방향 flag만 바꾸고 owner/ID/port/점 좌표를 보존한다. 잘린 촉·윤곽 안의 촉·glyph와 구분되지 않는 끝점은 승인하지 않는다. 단순 선/양촉/중간분기/교차/분리반대촉/owner접촉·이웃글자와 원형·사각형 양성, 여러 회전·크기·AA의 실제 raster 대조를 수행한다. 검증15는 개발 자료이며 GT는 출력 후 평가에만 사용한다.

초기 OpenCV 수평 화살표 양성에서 3개 기권이 발생했다. 일반 polarity stroke_mask가 검은 테두리 근처의 좁은 **흰 배경 틈**을 밝은 stroke로 잡아 촉 폭을 넓히는 것을 원본 RGB 열별로 확인했다. H의 밝은 배경 관측은 B와 같은 정수휘도<130 원본 어두운 잉크로 제한한다. S의 동결 마스크/문턱이나 원본 픽셀은 수정하지 않는다.

## 실제 경계에 닿은 filled triangle 계약

어두운 잉크 수정 후에도 2s 경계 제외 띠가 마지막 촉 픽셀을 가려 초기 양성3개는 기권했다. 1px 띠 시험은 실제 두꺼운 테두리가 남아 접촉 기권이 됐다. 무작정 띠를 줄이지 않고 2s를 유지한다. H는 **채워진 삼각 쐐기**로 범위를 제한하고 관측 가능한 양쪽 사선의 선형 수렴을 확인한다. S의 촉 검사를 완화하지 않는다.

밑변 후보는 S의 고정 폭/길이 규칙으로 찾고, 원본 head 픽셀의 물리 convex hull 면적 대비 점유율≥.80을 요구한다. T 글자의 횡단 폭 사이 공백을 삼각 채움으로 간주하지 않는다. 양쪽 경계의 선형 residual≤max(1px,s), 서로 수렴하는 기울기 절댓값>.15, 추정 꼭짓점이 관측 끝에서[-1 cell,4s] 이내, shaft 중심에서 shaft 반폭+1cell 이내여야 한다. 방향 flags만 고치며 열린 V 촉은 이 버전의 지원 범위가 아니다. 독립 T 반례는 원래 B gate도 모두 거부했지만 H 단독에도 방어를 둔다.
