# R10-P: 복잡 실제 그림의 폐윤곽 우선 박스 제안

## 원인과 목표

합성15에서 B/H/G는 높은 정밀도를 보였지만, 원래 `input.png`의 새 검출 결과는 큰 가짜 owner와 합쳐진 라벨을 만들었다. 후처리로 올바른 검출 bbox를 가정하면 이 앞단 오류가 해결되지 않는다. 기존 모델을 다시 훈련하거나 성능 좋은 crop을 고르기 전에 **원본의 닫힌 단순 사각 윤곽 자체를 후보로 만드는 별도 연구 경로**를 점검한다.

## 범위

- 입력 RGB만 사용한다. detector/GT/이전 장면/정답 PPT는 필요하지 않다. 모델 기반 경로의 동결 결과를 대체하지 않는다.
- Canny(20,60)와 Canny(40,100)의 실제 닫힌 hole contour가 같은 bbox로 일치해야 한다. morphology closing으로 경계를 만들지 않는다.
- 종횡비 1.15~15, 폭≥32s/높이≥16s(s=H/360), 내부 면적이 bbox의90% 이상이고 면적이 canvas25% 이하여야 한다. 둘레의 사각 경계 적합도도 검사한다. 원/아이콘/얇은 텍스트 조각을 새 node로 제안하지 않는다.
- 두 폐윤곽이 bbox IoU .85 이상이면 중복 또는 중첩 경계가 모호하므로 이번 버전은 둘 다 기권한다. 새로운 합치기 규칙을 정답 개수에 맞추지 않는다.
- 이미 닫힌 경계 안의 색만 샘플링하며 별도 내부 폐윤곽의 영역/띠를 제외한다. 불확실한 단색은 채우지 않는다.
- 서로 다른 두 OCR 확대에서 동일 문자열·신뢰도≥.95·동일 공간 범위를 가진 조각만 라벨에 넣는다. 아이콘 자체를 벡터화하지 않는다. 읽지 못한 라벨은 공백이다.
- OCR 조각은 세로 겹침으로 원본 줄에 묶고 줄 안에서 왼쪽부터 정렬한다. 조각별 높이로 나눈 y값 정렬은 서로 다른 크기의 단어를 잘못된 줄 순서로 보낼 수 있어 사용하지 않는다. 모든 조각이 확실한 동일한 완전한 줄만 처음부터 연속해서 남기며, 첫 불확실한 줄에서 멈춘다. 불확실한 단어를 삭제한 뒤 남은 문장 조각을 연결하지 않는다.
- 확대 두 개에서 같은 잘못된 OCR 문자열이 나올 수 있으므로 원본1배까지 포함한 1/1.5/2.25배 세 관측의 줄 일치를 요구한다. 정답 문자열로 교체하거나 불일치한 원본 관측을 다수결로 버리지 않는다.
- 먼저 편집 가능한 박스 초안을 실제 PowerPoint로 확인한다. 연결은 원본 두-owner 추적/C/B/H의 독립된 증거를 통과할 때만 추가하고, 채색/그림자로 구획을 창작하지 않는다.

## 검증

두꺼운 단일 사각 테두리는 Canny에서 안쪽/바깥쪽 폐윤곽 두 개를 만들 수 있다. 기본 모호성 기권으로 양성6개가 누락됐다. 좁은 포함 관계(경계 차이≤max(2px,3s))가 정확히 한 쌍이고, 두 윤곽 사이 실제 색 띠의90% 이상이 내부 대표색과24 이상 다르면 같은 ink band의 두 면으로 판단해 안쪽 윤곽 하나를 유지한다. 두 threshold의 bbox가1px 이내 일치해야 한다. 두 선 사이가 배경색인 진짜 중첩 사각형은 이 예외에 포함하지 않는다.

그림자·열린 박스·이웃/중첩 경계·원형/다이아몬드·텍스트·배경 색 변화와 실제 단순 폐사각의 합성 RGB 대조를 먼저 수행한다. 기존 `input.png`와 이미 소비된 복잡6개 development 자료에 고정 적용한다. 새로운 holdout을 열지 않으며, 부분 복원과 개별 문자의 정확성을 육안으로 평가한다. 모든 구조를 다 찾는 것이 목표는 아니다. 큰 가짜 박스를 없애고 실제 수정 가능한 확실한 최소 부분을 제공하는 것이 목표다.

초기 양성 fixture9개는 사각형 면적이 canvas의38%여서 사전25% 상한을 위반했다. 이를 알고리즘 누락으로 세거나 상한을 늘리지 않고, 같은 원본 사각형을 큰 canvas에 놓은 범위 내 양성을 별도로 추가해 검사한다.
