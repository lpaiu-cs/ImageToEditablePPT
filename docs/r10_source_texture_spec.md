# R10: 원본 내부 텍스처 거부 대조

이 대조는 실패한 단색 내용 gate의 대체 승인기가 아니다. **사진 내용을 먼저 가려 버린 뒤 남은 캡션을 승인하는 오류**를 막기 위해 자식 영역을 포함한 원본 폐윤곽 내부를 직접 검사한다.

긴변/짧은변이나 OCR와 무관하게 tile=max(12px,16s) 격자에서 채널8단위 양자화의48색 이상이며 평균 채널 표준편차6 이상인 복잡 tile을 센다. 실제 내부에80% 이상 포함되는 충분한 tile만 측정한다. 측정 픽셀의20%를 넘으면 거부한다. 이 기준을 먼저 고정하고 독립 사진/도식/텍스트/그라데이션 대조로 검사한다.

텍스처가 없다는 사실은 구조적 다이어그램임을 증명하지 않는다. 단색 사진·평면 일러스트·작은 비구조 요소는 이 검사로 보장되지 않는다. 무라벨 고립 경계는 기존 source/native 연결 조건으로 별도 기권하고, 사진 캡션 반례는 실제 OCR를 사용해 재검사한다. 원본RGB를 지우거나 사진을 단색으로 새로 그리는 기능은 없다.

기존 내용 gate와 동시에 실행하지 않는다. 이전 결과를 덮어쓰지 않고 `--texture-guard`의 별도 결과로 남긴다. 육안으로 확인한 부분 복원과 일반적 프로덕션 승인은 계속 구별한다.

첫 실제 도식 대조(`complex-texture-source`)에서 큰 anti-aliased 글자도 여러 색의 tile로 세어 과잉 기권했다. 다음 수정은 신뢰 OCR가 실제로 관측한 단어 bbox만 텍스처 계산에서 제외한다. 사진 캡션의 **자식 윤곽 전체를 제외하지는 않는다.** 기존 실패는 보존하고 실제 글자 양성과 사진 캡션 음성을 동시에 다시 검사한다.

단순 두 색 사이 anti-aliasing은 양자화 색 개수가 많아도 RGB 공간에서 거의1차원이다. v3에서는 색 공분산의 두 번째/첫 번째 고유값 비율≥.05도 함께 요구한다. 이는 두 색 글자·단순 색 변화를 사진처럼 거부하지 않기 위한 조건이다. **회색조 사진은 이 조건을 통과하지 않아 거부하지 못할 수 있다.** 해당 사각지대를 단위검사에도 명시하며 일반 semantic 분류 완성으로 포장하지 않는다.
