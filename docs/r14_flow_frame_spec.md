# R14 내용 승격 없는 외부 흐름 테두리 보완 — 사용자 승인

## 목적과 승인 경계

사용자는 이 작업의 '승인' 응답으로 연결형 사진/아이콘 카드의 내부를 생략하고 테두리·연결선을 남기는 출력 정책을 승인했다. 현재 texture veto는 사진 오출력을 막지만, 아이콘을 포함한 구조 카드의 테두리까지 제거한다. 사진2장으로 새 의미 분류기를 학습하는 대신 **외부 흐름의 폐테두리와 내부 비구조 내용을 분리**하는 별도 연구 arm을 구현한다. 기존 R11 결과는 보존하며 성능 검증 후 기본 CLI 채택 여부를 결정한다.

독립 검토에서 연결된 사진 프레임과 구조 카드 모두 같은 외부 흐름 조건을 만족할 수 있음을 확인했다. 따라서 외부 연결은 의미 분류의 증명이 아니다. 이 제안은 사진을 diagram으로 정확히 분류하는 수정이 아니라, **연결된 사진/아이콘 카드도 내부를 지우고 관측된 폐테두리만 남길 수 있도록 하는 출력 정책**이다. 이 허용 여부는 사용자 선택이 필요하다. 기존 단독 사진20개 blank 결과는 이 정책을 검증하지 않는다.

보완 대상은 같은 RGB 실행에서 관측된 실제 closed rectangle 후보다. texture에 의해 기권한 후보 중 다음 조건을 모두 만족한 것만 내부를 비운 테두리로 남긴다.

1. 기존 texture 통과 및 nonblank 라벨이 있는 owner만 고정 seed로 쓴다. 보완된 빈 테두리를 다음 seed로 사용하지 않는다.
2. 원본에서 추적된 두 독립 선이 대상의 서로 다른 물리 port에서 하나는 들어오고 하나는 나간다. 같은 seed와 왕복도 허용하되 port 거리는 원본8s 이상(s=H/360)이다. 동일 경로의 반대 복제는 허용하지 않는다.
3. 이번 arm은 `r3_stroke_trace`의 두 점으로 표현된 수평/수직 단일 arrow만 사용한다. 원본축 오차≤1px, start arrow 없음/end arrow 있음이어야 한다. native writer의 기존 경로 적합 검사를 통과해야 하며 제3 owner와 겹치는 선은 제외한다. 방향을 새로 추측하지 않는다.
4. 대상과 seed는 공간적으로 떨어진 NODE box다. 다른 실제 후보를 포함하는 parent는 제외한다. 내부 icon의 선을 외부 흐름으로 세지 않는다.
5. 내부 그림과 글자는 생략하고 no-fill과 label=None으로 테두리만 출력한다. 원본에서 관측하지 않은 white fill을 복원색으로 만들지 않는다. 관측 OCR은 audit에만 보존하며 후속 text placement에서도 되살리지 않는다. 사진/아이콘/장식 자체를 출력하거나 의미 분류 승인으로 바꾸지 않는다. 원래 texture eligible=false도 변경하지 않고 별도 frame-only 근거를 기록한다.
6. 기존 native writer의 경로 적합 helper를 재사용하며, 최종 emit 후에도 승인에 사용한 두 실제 부착 연결이 모두 남는지 재검증한다. 사라진 proposed edge만으로 고립 카드를 남기지 않는다.

`--compact-boxes`를 함께 사용하되 R12 raw-branches는 켜지 않는다. 이는 새 종횡비/texture/OCR cutoff 최적화가 아니다. 원본 card1개를 통과시키기 위해 수치를 변경하지 않는다. 사용자 입력 제목이 읽히지 않으면 빈 카드로 남으며 정확한 텍스트 성공으로 세지 않는다.

## 검증

고립 사진/캡션, 단방향 연결, 한 경로의 복제, 무라벨/texture 실패 seed, 내부 포함관계, native 미지원 경로, 제3 owner 교차는 기권해야 한다. 정상 왕복/별도 들어옴-나감 구조만 테두리 후보로 인정한다. policy unit test와 RGB→실제 PPT fresh 실행은 구별한다.

원본에서 최종 PPT를 직접 보고 보완된 카드/연결이 원본에 존재하는지 확인한다. 이어 기존 복잡7과 source PPT→COM32개를 다시 검사한다. 새로운 source PPT의 사진 포함 흐름 카드 양성은 **외부 테두리/연결만 정답**이고 내부 picture는 제외한다. 고립 사진 프레임은 계속 음성이다. 같은 RGB에 서로 모순되는 의미 라벨을 붙이지 않는다. 효과/안전성 확인 전 기본 경로에 채택하지 않으며 production 승인은 별도다.

연결형 사진+caption은 필수 의미 경계 사례다. 소스 내부 그림의 의미 판별 문제를 연결 개수 기준으로 조용히 대체하지 않는다. 승인 전 미연결 함수 초안은 제거했으며, 승인 후 구현과 실행 결과는 별도로 기록한다.
