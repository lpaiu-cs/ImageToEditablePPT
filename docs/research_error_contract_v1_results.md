# 오류 분류 계약 검증 결과

## 판정

새 offline 평가기는 기하 변화와 구조·내용 변화를 분리한다. 제품 합격/불합격 점수를
만들지 않는다. 명세 `1ed1c8c`, 구현/대조 `dcd237a`를 첫 unit 실행 전에 고정했다.
17개 대조가 모두 통과했다. 1px 및 20px 이동은 기하 차이로만 기록하며, endpoint가 같아도
target ID나 방향이 바뀌면 구조 차이가 검출된다. CP→CP. 변경도 내용 차이다.

## 동결 결과에 적용

동결 A-T와 C-v2의 같은15장·같은ID 결과를 읽어 새 진단을 생성했다. 추론, OCR, PPT 생성,
모델 학습을 다시 실행하지 않았다. SHA 검증 후 source와 emitted 경계를 각각 비교했다.

| 경계 | 구조/내용 변경 | 기하 변경 | metadata 변경 |
|---|---:|---:|---:|
| source scene | 0 | 6 | 0 |
| native emitted scene | 6(연결 추가) | 0(공통 객체) | 0 |

source에서 바뀐6개 경로의 최대 endpoint 변위는 각각 1.636, 4.199, 2.015, 2.667,
2.388, 2.719 원본 px다. 이미지 대각선 대비 약 .223%~.572%다. 이 수치를 경로 전체
오차나 실용 허용치로 해석하지 않는다. 실제 출력에서는 이전에 없던6개 연결이 새로
생겼으므로 공통 connector의 기하 변경이 아니라 연결 추가로 기록된다.

기존 별도 GT 평가에서 이6개 추가는 전부 TP였다. 즉, '구조 차이=실패'도 아니다.
새 비교기는 차이를 식별하고, 좋은 변화인지 나쁜 변화인지는 정답 관계 평가와 실제
육안 확인에서 판단해야 한다. 기존 32 TP / 5 FP / 35 FN 성적은 바꾸지 않았다.

## 이전 실패의 정확한 해석

- C-v1 1px endpoint 차이2건: 래스터 생성과 기대 좌표의 계약 불일치이며 실용 복원 실패의
  증거가 아니다. 나머지4건은 끊기지 않은 선을 잘못 기권한 픽셀 지지 정의 문제다.
- D-v1 회전/세로280건: 당시 unsupported 기권 계약 위반이다. 해당 owner 삭제가 모두
  실제 독립 글자 손실이었다는 뜻으로 확대하지 않는다.
- D-v1 partial Il16건과 punctuation80건: fixture에서 추가 획/점을 포함하는 bbox 대신
  부분 bbox를 남긴 반례다. 아직 실제15장 출력에서 문자 손실을 측정한 결과는 아니다.

기존 수치/기대값/결과파일은 그대로 보존한다. 새 실험에서는 이 분류를 함께 보고하며
작은 좌표 차이 때문에 전체 제품 실패라고 하지 않는다. 반대로 실제 객체·관계·문자
손실을 좌표 허용오차로 덮지 않는다.

산출물: `artifacts/region-source-evidence-r9/error-contract-v1/lock.json`, `results.json`.
실행기: `tools/assess_frozen_revisions.py`. 비교기는 동일ID 제어 대조에 한정되며 일반 GT
매칭기나 D-S 삭제의 옳고 그름을 판정하는 도구가 아니다. 사용자 수정시간은 미측정이다.

## 통합 확인

평가분리17개 + C-v2 43개 + D-v1 입력경계12개는 72 passed다.
현재 전체 pytest는 559 passed / 6 failed / 2 xfailed / 9 warnings로 종료했다.
6개 실패는 위에 설명한 동결 C-v1 테스트이며 새로운 제품 퇴행으로 세지 않는다.
전체 테스트가 성공했다고 주장하지 않으며, 기존 학습 smoke test 실행을 새 학습 실험으로 세지 않는다.

D-v2 명세는 별도 작업의 c35f654/65b56cd/e778ac를 검토해 root의 dc3c254/872bfa7/4b5655f로
통합했다. 직접 관측하지 못하는 개별 glyph 자세를 행 방향 판정으로 검증했다고 주장하지
않도록 고쳤고, TLS 각도 여유를 엄밀한 오차 상한이 아닌 휴리스틱으로 명시했다.
명세 검토 후 별도 작업에서 구현·fixture 잠금·G0~G2 진행을 승인했다. 이 보고서 작성 시점에는
D-v2 반례 성적이 아직 없으며 실제15장/C결합/제품 승격을 수행하지 않았다.
