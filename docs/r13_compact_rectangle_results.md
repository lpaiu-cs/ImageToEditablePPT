# R13 사각 종횡비 공백 수정 실험: 최종 출력 개선 없음

## 확인한 원인

`4f413ab`에서 거의 정사각형인 실제 폐윤곽만 추가하는 별도 옵션을 만들었다. 닫힌 사각3종은 통과하고 원/다이아몬드/열림/작은 badge는 기권하는7개 대조를 통과했다. 원본 RGB fresh 실행에서 User Input 카드가 후보가 된 것은 확인했다. 그러나 **후보 누락만 없애면 실제 출력이 좋아진다는 가설은 성립하지 않았다.**

카드의 최종 탈락 원인은 두 개가 남았다.

1. 원본 전체 행 OCR은 같은 `User Input`을 관측하지만 confidence가.949449/.982517/.953034로 기존.98 기준을 모두 넘지 못한다. 원본 잉크 행 인식도.950172/.980154/.961649이다. 분리 인식은 `User`와 `Input`/`rInput`의 중첩 창을 만들며 이를 이어붙이지 않는 것이 맞다. 텍스트를 정답으로 덮어쓰거나 threshold를 낮추지 않았다.
2. 카드 전체 관측영역의 texture 비율은.228975로.2를 초과하며, veto를 만든 두 tile이 인물 아이콘 위치와 겹친다. 이 비율을 아이콘의 분류확률이나 아이콘 자체의 비율로 해석하지 않는다. 현재 사진 방어는 '아이콘이 포함된 구조 카드'와 '캡션이 있는 사진 프레임'을 의미적으로 분리하지 못한다. 해당 카드의 전체 기권은 이 한계의 구체적인 사례다.

## 결과와 판정

원본 결과는 R11과 동일하게7도형/7라벨/2native연결/삽입이미지0이다. 실제 COM 비교 화면을 직접 확인했으며 원본 결과 PNG는 R11과 byte-identical이다. SHA `3fab2aefdf103acde472fcdf08aa8bdd4c496013198823cd57434b1f01efeb6d`. native bbox/라벨/양종점·입력/PPT/COM 감사도 통과했다.

산출물은 `artifacts/region-image-only-r13/compact-v1/original`, 감사는 `compact-v1-review/audit.json`이다. 옵션이 입력한 실제 카드 후보와 기존 owner ID 순서를 바꾸지만, 개수뿐 아니라 최종 렌더도 같다는 점을 확인했다.

사전 명세의 원본 효용 조건을 만족하지 않았으므로 **복잡7/기존32 전체 확장 실험은 하지 않으며 기본 CLI에 넣지 않는다.** 여기서 중단하는 것은 효용 없는 compact arm의 확대이며, 전체 문제가 해결됐다는 뜻이 아니다. 옵션과 실패 근거는 연구 재현용으로 남긴다.

## 남은 문제의 경계

현재 성능을 막는 것은 더 이상 하나의 종횡비 cutoff나1픽셀 판정만이 아니다. 아이콘이 포함된 구조 카드의 지역 분리, 낮은 OCR confidence의 실제 오류율 교정, 복잡 연결의 접합 의미와 native 표현 누락이 서로 다른 병목이다. 사진 원본2개의 파생 예시와 이미 노출된 복잡7개만으로 일반화 해결을 선언할 근거는 없다.

단지 원본 한 장을 통과시키기 위해 texture·OCR 기준을 낮추면 앞서 실제로 발생한 사진 오출력을 다시 허용할 수 있다. 사람의 검토 없이 사용할 완성본이라는 승인도 내리지 않는다. 현재 검증된 결과는 R11 이미지 단독 partial draft이고, R12/R13은 기본 미채택 연구다. 실제 사용자 수정시간 감소는 별도 인간 측정이 필요하다.

최종 전체 회귀는1346 passed/기존2 xfailed/9 warnings다(`artifacts/region-image-only-r13/regression.xml`). 역사적 C-v1 파일의 별도 동결 제외 경계는 유지했다. 이는 새 모델의 정답률이나 프로덕션 승인률이 아니다.
