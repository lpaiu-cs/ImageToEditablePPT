# R10-P 내용 승인: 닫힌 경계만으로 의미를 승인하지 않기

## 근거

독립 사진 프레임 진단은 안쪽 경계 선택에서3개→7개로 늘었다. 이는 실제 테두리를 더 찾은 것이지 사진을 diagram으로 판별한 개선이 아니다. glyph 구멍도 실제 폐사각이다. 닫힘만으로 전부 출력하면 프로젝트 범위를 위반한다.

## 새 실험의 고정 계약

`--content-gate`는 기존 제안기와 별도로 다음을 적용한다.

1. 내부 실제 소유 영역에서 자식 경계와 신뢰 OCR 단어 창을 제외한다. 원본 RGB를 바꾸거나 그림 영역을 새로 그리지 않는다.
2. 남은 내부가 충분히 있고(최소12px 및 소유영역10%), 채널 최대차24를 넘는 픽셀이 중앙값 기준5% 이하여야 단순 내부로 인정한다. 사진/아이콘 등 미설명 내용이 크면 경계 자체도 출력하지 않는다.
3. 신뢰 라벨이 없으면, 내부 검사를 통과한 라벨 있는 owner와 실제 원본 추적 연결이 있어야 남긴다. 글자 없는 고립 glyph 구멍을 새 node로 승인하지 않는다.
4. 탈락 owner의 연결도 함께 제거한다. 남은 native 연결은 기존 emitter 적합도/실제 부착 검사를 통과해야 한다. 승인된 연결 없이 남은 무라벨 노드는 최종 단계에서도 제거한다.

이 기준은 일반적인 사진/아이콘 의미 분류기를 완성했다는 뜻이 아니다. 단색 배경 비중이 큰 사진 등은 별도 미해결 범위이다. 수치만으로 프로덕션 승인하지 않고, 이미 노출된 복잡7개를 새 출력으로 렌더링하여 실제로 남긴 부분이 유용하고 잘못된 구조가 없는지 다시 본다. 정보가 부족하면 채택량이 감소할 수 있다.

독립 photo/glyph/blank rectangle/실제 라벨 박스/연결된 공백 박스의 양성·음성 통제를 포함하고, 과거 P1/P2 진단 수치를 수정하지 않는다.

## 현재 판정: 채택하지 않음

기본 내용 gate는 기존 사진 프레임7개를 막았지만, 별도 독립 fixture의 사진 캡션 프레임은 사진 영역을 자식으로 제외한 뒤 실제 OCR `PHOTOID`를 승인했다. 또한 원본 복잡 그림에서10개 박스가1개로 줄어 유효 부분 복원량이 지나치게 감소했다. 따라서 이 옵션을 프로덕션 기본 경로로 사용하지 않는다. 성공한 소유 영역 분리·라벨 배치 수정과 이 실패한 의미 gate는 구별한다. 자세한 실제 OCR 반례는 `r10_content_gate_audit.md`에 보존한다.
