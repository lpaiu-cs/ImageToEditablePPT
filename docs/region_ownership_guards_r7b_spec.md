# R7b: 미출력 객체의 경로 차단과 소유 영역 채움

## 실험 경계

R7 오라클 결과를 본 뒤 설계한 후속 개발 실험이다. R7의 명세·입력·코드·결과는
그대로 동결한다. 같은 네 개발 영역을 사용하며 독립 검증이나 사전 미관측 결과가 아니다.
프로덕션 런타임은 변경하지 않는다. 역할 정답에 의존하므로 자동 변환 개선으로 주장하지 않는다.

육안 근거: P084의 미지원 원통 테두리를 추적하여 annotation→model,
model→batch의 거짓 지름길이 만들어졌다. P159의 부분 영역 바깥에서 들어오는
공유 입력을 residual→conv-lower로 오인했다. p058은 부모의 내부 샘플에 자식
색이 섞이고 옅은 회색 자식이 투명 처리되어 부모색이 비쳤다.

## 이번 변경과 순서

1. 출력 불가지만 존재가 확인된 구조적 객체를 삭제하지 않고 비출력 차단 영역으로 유지한다.
   주석상의 미지원 원통 상자를 3픽셀 확장하고 주변 3픽셀 띠의 중앙색으로 중립화한다.
   이 범위는 정답 제공에 의존하는 진단 장치다. 그 객체를 사각형으로 출력하지 않는다.
2. 기존 추적의 연결 성분이 선택 영역 경계 2픽셀 띠에 닿으면 외부 소유 관계 미확정으로
   그 성분의 연결을 보류한다. 정답 연결 목록을 필터에 사용하지 않는다.
3. 닫힌 승인 객체 내부에서 자손과 비구조/불확실 영역을 제외해 채움색을 계산한다.
   안쪽 여백은 짧은 변의 6%, 최소 3/최대 12픽셀이다. RGB를 16단위로 양자화한
   최빈 군집이 60% 이상이고 남은 픽셀이 64개 이상일 때만 그 군집의 중앙색을 채운다.
   흰색·옅은 회색도 관측된 닫힌 내부의 색이면 불투명 채움으로 유지한다.
   경계색이 채움과 구별되지 않으면 중립 테두리로 남긴다. 제목이나 누락 텍스트는 만들지 않는다.

차단 전(R7), 차단만 적용, 경계 성분 보류까지 적용한 추적 결과를 따로 기록한다.
최종 장면만 native PPT로 렌더한다. 색 변경은 동일 기하/라벨에 적용하므로 OCR 개선으로 세지 않는다.

## 검증과 판정

- 지원 가능한 확실한 객체·직접 연결의 보존 여부와 거짓 연결 감소를 각각 센다.
- 실제 픽셀의 부모/자식 색이 구분되는지, 아이콘이 채움에 섞이지 않는지 렌더를 직접 본다.
- 원통 4개, 점선·곡선 연결 누락은 계속 실패/미지원으로 기록한다.
- 외부 경계에 닿는 실제 연결도 보류될 수 있으므로 회수율 비용을 숨기지 않는다.
- 단순 synthetic 양성/음성 대조군, 좌표/타입 경계, 기존 전체 테스트를 실행한다.
- 실행 전 코드 해시를 새로 동결하고 R7 동결 파일은 수정하지 않는다.
- 결과가 좋아도 역할 정답 없는 새 출처 집합 검증 전에는 제품 승격하지 않는다.

완전한 stroke-piece 그래프, 원통 native 표현, 역할 분류기 학습은 이번 변경에 포함하지 않는다.
