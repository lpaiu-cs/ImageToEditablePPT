# R13 거의 정사각형인 폐사각 후보의 누락 점검

원본 CogBot의 User Input 카드는 Canny의 실제 닫힌 윤곽([1303,46,1506,246], 면적비 약.967)이 있지만, 가로/세로 후보의 종횡비 하한1.15 사이에 놓여 후보 자체가 되지 않았다. 구조적 카드와 내부 인물 아이콘은 별개이며, 카드의 선·라벨만 변환하는 것은 프로젝트 범위다.

R11 기본 구성과 R12 실험은 바꾸지 않는다. 새 compact_boxes arm은 기존 가로/세로 조건 사이의 공백만 보완한다: 1/1.15≤폭/높이≤1.15, 양변≥32s(s=H/360). 실제 폐윤곽, 면적비≥.90, canvas면적≤.25, 경계 적합도, 두 원본 threshold의1픽셀 일치 및 중복 배제는 그대로다. 기존 작은 badge/아이콘을 구제하기 위해 크기 하한을 낮추지 않는다.

이 옵션은 도형 후보만 바꾼다. R11의 소유영역 분리·OCR·texture·native 편집 가능성 검사는 그대로 적용하며 아이콘을 재구성하지 않는다. R12 raw_branches는 함께 켜지 않는다. 사각/원/다이아몬드/열린 경계 대조를 먼저 검사하고, 원본 RGB에서 실제 카드와 텍스트가 유용하게 나오는지 육안 확인한다. 원본에서 효용이 없으면 추가 대규모 실험을 하지 않는다. 효용이 있으면 복잡7 및 기존32입력의 독립 회귀를 한다. 새 holdout이나 과거 정답 장면을 추론에 넣지 않는다.
