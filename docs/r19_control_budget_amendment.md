# R19 양성 대조 학습량 점검

2026-09-09.100step control-v1은TP0/FP0/FN25로 실패했다. 낮은.05출력은100개 존재하고 상위score는.224수준이었다. 원본객체위치주변의여러종류후보는생겼으나.5기준을넘지못했다. 코드/모델의FrozenBN구조일치와CUDA실행은확인했다. 새R19 calibration/eval픽셀은아직열지않았다.

이실패를삭제하거나원래100step결과를성공으로바꾸지않는다. 학습량부족가설을검사하기위해**동일R18대표train5장/동일seed1901/동일초기화/동일batch2/lr.0003으로새로600step**을학습한다. geometry recall≥.9/strict recall≥.8,score.5기준은유지한다.100/300/600step에검사/그림을저장하되600의최종결과만본학습gate로사용한다. extension은기존동결runner/model을수정하지않는별도도구다.

통과하면원래R19 train288/1800step설계로진행한다. 실패하면R19미개봉eval을보존하고별도원인을진단한다. 이는학습가능성대조수정이며일반화평가조건을실패뒤바꾸는구제가아니다.
