# R7: 승인 객체 경계와 오라클 복원 한계 실험

## 상태와 목적

R6 동결 커밋 `0b9c699`에서 분기한 연구 전용 실험이다. R6의 일반화 실패와
승인된 v0.3을 변경하지 않는다. 자동 인식 성능 개선이나 프로덕션 승인을 주장하지 않는다.
이 명세는 R7 결과를 보기 전에 작성한다.

검증 질문은 두 가지다. 역할과 소유 관계가 정확할 때 지역별 후보 생성으로
누락 객체를 더 찾을 수 있는가? 정확한 소유 객체를 주어도 연결 추적이 실패하는가?
후자가 실패하면 역할 분류기 학습을 시작하지 않고 표현 계층을 먼저 고친다.

## 이번 단계의 데이터 경계

- p058: 원본 좌표 `[470,190,1015,575]`의 LLM 중첩 패널. 부모/자식과 라벨 혼합 검증.
- P084: 전체 그림. 원통형 소유 객체, 곡선/점선 연결과 아이콘 배제 검증.
- P159: 원본 좌표 `[480,110,1098,1000]`의 오른쪽 사각형 연산 노드. 직접 연결 양성 대조군.
- P009: 전체 사진/차트 혼합 그림. 구조적 다이어그램 비대상 음성 대조군.

모두 R6에서 이미 관측한 개발 자료다. 선택은 알려진 실패 유형에 근거하며 무작위
표본이나 미관측 일반화 평가가 아니다. p058/P159는 명시한 부분 영역만 평가한다.
Phase16 holdout 및 기존 좌표가 혼합된 p034 주석은 접근·수정하지 않는다.
새 데이터 수집과 출처 그룹별 개발/보정/승인 분리는 후속 학습 단계의 선행 조건이다.
이번에는 보정/승인 집합을 만들거나 소비하지 않는다.

## 주석과 형식 경계

새 주석은 원본 SHA-256, 원본 크기, 부분 영역, 표시→원본 좌표 변환을 기록한다.
모든 상자는 원본 픽셀의 반개구간이다. 원본 크기의 육안 확인을 사용하므로 변환은
배율 1, 오프셋 0이다. 주석 오버레이를 다시 확인하고 실행 전에 해시를 동결한다.
역할은 node/container/connector/port/nonstructural/unknown으로 구분한다.
부모는 명시하며 순환·범위 위반·알 수 없는 참조를 거부한다. 비구조/불확실 영역은
사각형 제외 마스크로 기록한다. 연결 정답은 실제로 관측된 방향 및 양 끝 객체만 기록한다.

`CandidateScene`과 `AcceptedScene`을 분리한다. 연구용 OCR/추적 함수는 후자만
받는다. 승인 전에는 라벨과 연결이 없으며, 오라클 주석의 정답 텍스트를 OCR 입력이나
출력으로 복사하지 않는다. 원통을 사각형 또는 타원으로 바꾸어 성공으로 세지 않는다.
원통은 현행 소유 객체 표현 미지원으로 기록한다. 자동 CLI에는 오라클 경로를 연결하지 않는다.

## 고정 실험군

1. R6 전체 영역 후보 + 기존 선택: 기존 기준 장면.
2. 전체 영역 후보 + 고정 지역 타일 후보: 후보 회수율 실험.
3. 1의 후보에 정답 역할/소유 관계로 승인: 전역 후보 오라클.
4. 2의 후보에 같은 오라클로 승인: 지역 후보 오라클.
5. 정답 원본 상자와 역할을 직접 공급: 기하 오라클. 자동 인식 결과가 아니다.

타일은 512픽셀, 간격 384픽셀, 마지막 가장자리 타일을 포함한다. 확대/축소하지 않는다.
잘린 타일 경계 2픽셀 이내 후보는 제외한다. 전역 후보는 보존하고 IoU 0.90 이상
중복만 제거한다. 정답으로 타일 위치나 후보 생성 파라미터를 정하지 않는다.
매칭은 IoU 0.70 이상, 각 변 오차 8픽셀 이하의 결정적 일대일 탐욕 매칭이다.
클래스는 매칭에 사용하지 않고, 승인 후 정답 역할을 공급한다. 모든 임계값은 고정한다.
오라클 승인 후 거짓 객체 0개는 정답 제공의 결과이지 분류 정확도 증거가 아니다.

## 측정과 중단 기준

- 전체/지원 가능한 객체의 후보 회수율, 역할 오류, 중복 및 미매칭 후보를 분리한다.
- 승인 객체 수, 부모 참조, 제외 영역 안의 잘못된 객체를 별도로 기록한다.
- 라벨 완전 일치와 잘못된 라벨을 따로 센다. 컨테이너 제목은 이번 OCR 대상이 아니다.
- 관측 연결과 방향의 TP/FP/FN, native 출력 단계의 누락을 분리한다.
- 원통, 점선, 곡선, 잔차 합산은 실패하더라도 사례에서 빼지 않는다.
- 원본/후보/승인/실제 PowerPoint 렌더를 직접 확인한다.
- 오라클에서도 핵심 구조가 누락되면 모델 학습과 제품 승격을 보류한다.
- 기존 런타임 파일 해시와 회귀 테스트를 확인한다. 새 wheel을 배포하지 않는다.
- 자동화 실행 시간은 사람의 수정 시간 절감 근거로 쓰지 않는다.

## 예상 후속 설계

결과에 따라 소유 객체의 복합 폐곡선 표현, 관측 stroke-piece 그래프, 독립된
화살촉 증거와 불확실 교차점 표현을 우선한다. 출력 수가 늘었다는 이유만으로
역할 분류기나 낮은 전역 면적 임계값을 다음 해법으로 확정하지 않는다.
